# 链场 OS

物流供应链**现场操作系统**。每个业务流程是一场可插拔的「场景」；调度台 / 司机端 / 门岗台 / 提货窗口协同办理，用语为**工作语言**（指令、报到、核验、签收、离场），不是片场对白。

## 产品原则

- **流程即场景**：先做核心引擎 + 工位壳，再不断加戏（干线提送、异常处置等）
- **真实干活**：工单号、口令、核验项、作业记录；不做夸张数字看板
- **人对岗**：切换工位办理本票，而不是填一张大表

## 当前场景

|------|------|

首场闭环：`派车 → 到闸 → 入场核验 → 备货 → 提货签收 → 离场`
